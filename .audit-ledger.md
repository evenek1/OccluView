## Полный прогон тестов (волна 4, разрешён пользователем)

Тесты гонялись целиком. Первый прогон дал 4 падения, все закрыты в `4a96390`:

- `set_scene` завершал живой drag через `discard` — append терял позу без записи
  в историю. Вернул `abandon_align_drag` (коммит-форма).
- `start_next_queued_load` отказывал ЛЮБОМУ Replace в очереди, включая новейший
  (наследника superseded-декода). Запрет снят.
- BOM-prefixed бинарный STL не проверялся по формуле размера после снятия BOM.
- `BridgeSplitController::cancel` подменял воркер на дефолтный, теряя
  инжектированный compute; теперь `abandon()` перезапускает поток поверх того же
  compute.
- i18n-пин 691 → 693 (в волне добавлено 6 ключей, удалено 4).

После правок: `cargo test --workspace --all-targets` — 0 падений (~2100 тестов),
`fmt` чисто, `clippy -D warnings` — 0, all-features (hps+formats) — 0.

см. `docs/remaining-work.md` (88 пунктов, разложены по приоритетам).
