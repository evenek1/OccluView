- [x] OFF: счётчики в строке ключевого слова; резервирование по БАЙТАМ (было x12).
- [x] glTF: индекс-сентинел отвергается; индекс-аксессор обязан быть SCALAR.
- [x] BOM UTF-8: PLY, ASCII STL, probe.
- [x] PLY-писатель: текстура сверх лимита читателя отбрасывается (было молча).

- [x] OBJ: потеря альфы теперь предупреждение (`VertexAlphaNotWritten`).
- [x] HPS: BOM/фиксы прошлой волны.
